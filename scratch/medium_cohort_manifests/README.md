# Reconstructed Medium-Mode Cohort Manifests

## Overview
These manifests represent the exact cohort partitions used during the medium-mode training, validation, and held-out test evaluations of the Explainable Multimodal Quantum-GNN framework.

> [!IMPORTANT]
> **Post-Training Reconstruction Notice:**
> These manifest files were reconstructed after training using the existing deterministic dataset preparation pipeline (`src/training/execution_modes.py:prepare_mode_datasets()`) with fixed `seed=42`. They are not original manifests saved during the Colab training execution, because training-time code constructed the medium cohorts dynamically in memory without serializing standalone split CSVs.

## Source Files & Generation Procedure
- **Source Full Splits:**
  - `data/splits/train.csv` (79,006 scans, 21,563 patients)
  - `data/splits/val.csv` (16,460 scans, 4,621 patients)
  - `data/splits/test.csv` (16,654 scans, 4,621 patients)
- **Generation Method:**
  `src.training.execution_modes.prepare_mode_datasets(train_df, val_df, test_df, mode_cfg=get_mode_config('medium'), seed=42)`
- **Configuration Constraints:**
  - `target_train_scans`: 4,000 (actual resulting: 4,001)
  - `target_val_scans`: 800 (actual resulting: 800)
  - `target_test_scans`: 800 (actual resulting: 801)
  - `max_scans_per_patient`: 5 (uniform equidistant subsampling for patients exceeding 5 scans)
  - `seed`: 42 (deterministic permutation order for patient clusters)
